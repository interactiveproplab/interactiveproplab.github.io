# Interactive Prop Lab

Bespoke protogen hardware with live facial tracking and character-responsive expression mapping.

This repository contains the production files for the Interactive Prop Lab website and browser-based facial tracking demo.

## Live Demo

https://interactiveproplab.github.io/

Facial tracking runs locally in the browser using MediaPipe. Camera access is only requested when the demo is started.

## Commissions

A small number of bespoke protogen builds are available, including custom fabrication, live facial tracking, display integration, ventilation, fitting, and per-user calibration.

See the website for current details and contact information.
