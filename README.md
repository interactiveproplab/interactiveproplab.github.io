# Interactive Prop Lab

Bespoke interactive cosplay hardware with live facial tracking, responsive mechanisms, and character-specific behavior.

This repository contains the production files for the Interactive Prop Lab website and browser-based facial tracking demo.

## Live Demo

https://interactiveproplab.github.io/

The demo uses your camera to track facial movement including gaze, blinking, eyebrow movement, and mouth state, then maps those signals into a stylized character output.

Facial tracking runs locally in the browser using MediaPipe. Camera access is only requested when the demo is started.

## What I Build

Interactive Prop Lab focuses on wearable character systems and responsive cosplay hardware, including:

- screen-faced and LED characters
- animatronic masks and helmets
- tracked eyes and additional eyes
- moving jaws and facial mechanisms
- responsive props and creature features
- bespoke performer-driven electronics

Tracking and movement can be tuned around the character rather than mapped literally, allowing expressions and mechanisms to be exaggerated, softened, or remapped as needed.
